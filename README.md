## 40Gbps 到底贵在哪

40Gbps 理论吞吐约 5GB/s，是 1Gbps 端口的 40 倍。这个倍数在两类业务上才体现价值：一类是出口带宽直接决定收入，比如按流量计费的 CDN、按并发收费的直播；另一类是单次传输量极大，比如 TB 级数据跨机房同步，1Gbps 要跑一天，40Gbps 一两个小时结束。

真正让这档价格站住的是“不限流量、无超量计费”这几个字。云厂商按出口流量计费，1PB 流量账单能顶几个月独服租金；RackNerd 这六款给的是固定月费，流量跑多少都是这个价。带宽成本变成可预算的固定支出，这对做流量生意的人是刚需。

另外两个隐性价值：5 个可用 IPv4 直接包含在套餐里，不用额外买；IPMI/KVM 带外管理是标配，系统搞挂了能自己进控制台救回来，不用干等工单。便宜独服商经常在这两处省钱。

第三方测评里提到过洛杉矶机房到国内的延迟和智能路由表现，那些是作者自己的测试环境，没有官方 SLA 背书，我这里不当作参数引用。机房选择按用户位置判断就行：亚太用户选洛杉矶，北美东部和欧洲选新泽西，欧洲本地选伦敦，加拿大选蒙特利尔。

## 购买路径和四个容易踩的坑

**官网常规套餐和频道特价是两条完全不同的购买路径。** 40Gbps 六款在官网下单，购物车里填 15OFFDEDI；频道限量特价官网看不到价格，要在 Telegram 上联系官方销售 @alenxu，开口前把配置和月付价发过去。

四个坑：

1. **100TB 不等于不限流量。** 40Gbps 系列是真不限量、无超量计费；1Gbps 促销绝大多数标的是 100TB 流量。这两个口径不能混。
2. **“限量 N 台”是放出时的数量。** 几小时后可能就没了，页面上的记录不代表当前库存，只能作为参考。
3. **频道原文没写带宽是否独享。** 1Gbps 促销机不要默认独享端口，需要就在联系销售时问清楚。
4. **价格是美元月付，税费未说明。** 频道和官网套餐页都没写含税，按不含税理解，最终以账单为准。
